# Bioxflow website

Source of https://www.bioxflow.co.uk, built with Astro and Tailwind CSS.

    npm install
    npm run dev      # local preview
    npm run build    # production build in dist/

Pushing to `main` deploys the site. Pipelines are listed in `src/data/pipelines.ts`;
the contact form key is set in `src/data/site.ts`.
